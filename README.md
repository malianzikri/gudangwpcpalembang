## Deploy
Replace isi repository/project Vercel lama dengan seluruh isi folder ini, commit, lalu tunggu Vercel redeploy. Domain canonical sudah sesuai: `https://gudangwpcpalembang.vercel.app`.

## Setelah deploy
1. Cek homepage, halaman WPC/PVC/Wallboard/UV Marble, galeri, dan tombol WhatsApp.
2. Submit ulang sitemap di Google Search Console: `/sitemap.xml`.
3. Request indexing homepage, WPC, PVC, Wallboard, UV Marble, dan galeri.
4. Jika alamat gudang/Google Maps sudah siap dipublikasikan, tambahkan ke footer + schema LocalBusiness agar local SEO lebih kuat.

## Catatan harga
Harga acuan yang tampil: WPC Rp75.000/keping; Wallboard 40 cm Rp150.000/keping; Wallboard 60 cm Rp260.000/keping; UV Marble Rp550.000/lembar. Harga PVC tetap diarahkan ke WhatsApp karena variasi panjang/motif. Semua harga diberi disclaimer dapat berubah.
